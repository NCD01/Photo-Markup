## v0.42 - 2026-08-20

Linked changelog entries:
- `v0.42 - 2026-08-20`

Scope:
  - New RecoveryService: debounced autosave of the whole markup document, written to a .partial name then renamed so an interrupted write leaves the previous good copy.
